# Bitago MERN Activity

This workspace is organized into the requested folders:

- `bitago-client` - Vite React frontend
- `bitago-server` - Express and Mongoose backend

## Frontend

```bash
cd bitago-client
npm install
npm run dev
```

## Backend

```bash
cd bitago-server
npm install
copy .env.example .env
npm run dev
```

Set `MONGO_URI`, `PORT`, and `JWT_SECRET` in `bitago-server/.env`.
