# bitago-server

Express and Mongoose API for the Bitago MERN activity.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env`.
3. Set `MONGO_URI`, `PORT`, and `JWT_SECRET`.
4. Start MongoDB locally or use a MongoDB Atlas connection string.
5. Run the API:
   ```bash
   npm run dev
   ```

The default API base URL is `http://localhost:8800/api`.
